# Login and account access

- Explain the password reset link and what happens next: a message arrives at
  the address on the account, and the customer sets a new password from it.
- Never ask for a password, a one-time code or a recovery key, and tell the
  customer never to send one.
- Never confirm whether an address has an account to anyone but its owner. Say
  that if an account exists, the reset message will arrive at that address.
- If the customer says someone else has taken over their account, or the
  address on it was changed without them, do not try to fix it in a reply. Say
  that a person will look into it.
- Ask what the customer sees when the login fails: the exact message and the
  address they use, so the team does not have to ask again.
